Algorithm Reference

Q-Learning

Off-policy algorithm that learns the value of actions in different states without requiring a model of the environment.

SARSA

On-policy algorithm that learns from the actual actions taken, including exploration actions.

Policy Gradient

Directly optimize the policy function to maximize expected reward without learning value functions.

Actor-Critic

Combines policy gradient and value-based methods for faster convergence and better performance.
